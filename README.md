# 🧘‍♀️ Real-Time Yoga Pose Detection for Self-Learners

This project uses deep learning and computer vision to help individuals practice yoga by detecting and correcting body poses in real-time. It is designed for self-learners who want to improve their posture without needing a physical trainer.

## 🚀 Features
- Real-time yoga pose detection using webcam
- Feedback on incorrect postures
- Pose comparison with ideal yoga poses
- Easy-to-use interface for self-practice

## 🧠 Technologies Used
- Python
- TensorFlow / OpenPose / MoveNet
- OpenCV
- NumPy
